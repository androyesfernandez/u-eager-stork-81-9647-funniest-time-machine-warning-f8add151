# Funniest Time Machine Warning Label

A one-line warning label for a time machine — do not marry your great-grandmother — written by a small Node 22 program that drops the label into `/output/entry.txt`.

## The label

> WARNING: Do not marry your great-grandmother. The wedding is lovely, the honeymoon awkward, and you are the best man.

## How it works

`main.ts` (Node 22, no dependencies) writes the 117-character label to `/output/entry.txt` with no trailing newline:

```sh
node main.ts
```
